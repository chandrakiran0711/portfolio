## 🌟 Features

- **Interactive 3D Planet Visualization** - Rotating Earth with day/night cycle and city lights
- **Orbital Tech Stack Display** - Flip cards showing technology icons with smooth animations
- **Animated Timeline** - Career journey with a moving steam train animation
- **Particle System** - Magnetic cursor with sparkle trail effects
- **Parallax Scrolling** - Layered city skyline with depth
- **Responsive Design** - Works seamlessly on all devices
- **Smooth Animations** - Scroll reveals, hover effects, and transitions

## 🚀 Quick Start

### View Online
Visit the live portfolio: [https://your-portfolio-url.vercel.app](https://your-portfolio-url.vercel.app)

### Run Locally
1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
cd portfolio
```

2. Open in browser:
```bash
# Simply open the HTML file in your browser
open index.html
# or
start index.html
# or double-click the file
```

That's it! No build process needed - it's pure HTML, CSS, and JavaScript.
